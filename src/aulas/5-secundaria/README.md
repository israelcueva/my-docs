Esta sección corresponde al quinto grado de educación secundaria. Los recursos y programas usados se detallan a continuación:

## 1. Programas a usar

El alumno deberá tener instalado en sus computadoras los programas siguientes para el desarrollo de las tareas en casa. La lista corresponde a los programas que se usarán en todo el año.

> [!important]
> - ::logos:visual-studio-code:: ::logos:python:: **Ambiente de desarrollo:** Deberás [instalar la extensión de Python](https://www.youtube.com/watch?v=-IyA_Yvs8IQ) para Visual Studio Code.

- ::mdi:microsoft-office /red:: **Office:** La suite de Office es un conjunto de herramientas de productividad desarrolladas por Microsoft, ideales para el trabajo académico y profesional. Incluye programas como Word, Excel, PowerPoint y Acces.
- ::streamline-color:live-video:: [**VSDC Free video editor:**](https://www.videosoftdev.com/es/free-video-editor/download) Es un software gratuito de edición de video no lineal, ideal para crear proyectos profesionales con efectos visuales y transiciones. Ofrece herramientas avanzadas como corrección de color, motion tracking y edición multipista.
- ::logos:visual-studio-code:: [**Visual Studio Code:**](https://code.visualstudio.com/Download) Es un editor de código fuente ligero y multiplataforma desarrollado por Microsoft, diseñado para programadores que buscan rapidez, personalización y potentes herramientas de desarrollo. Ofrece soporte para múltiples lenguajes de programación, integración con control de versiones como Git, y una amplia biblioteca de extensiones que permiten ampliar sus funciones. Su interfaz intuitiva y su alto rendimiento lo han convertido en una de las opciones favoritas entre desarrolladores de todo el mundo.
- ::logos:python:: [Python](https://www.python.org/downloads/) Es un lenguaje de programación interpretado, versátil y fácil de aprender, ampliamente utilizado en campos como el desarrollo web, la ciencia de datos, la inteligencia artificial y la automatización de tareas. Su sintaxis clara y legible permite escribir código de forma rápida y eficiente, fomentando buenas prácticas de programación. Además, cuenta con una extensa comunidad y una gran cantidad de bibliotecas que facilitan la creación de proyectos de todo tipo, desde simples scripts hasta aplicaciones complejas.
- ::logos:mysql:: [MySQL](https://www.apachefriends.org/es/index.html) Es un sistema de gestión de bases de datos relacional de código abierto, muy popular en el desarrollo de aplicaciones y sitios web. Permite almacenar, organizar y consultar grandes volúmenes de información utilizando el lenguaje SQL (Structured Query Language). Es conocido por ser rápido, seguro y confiable, además de ser multiplataforma y contar con gran compatibilidad con lenguajes como PHP, Python o Java. Se utiliza ampliamente en sistemas de gestión de contenidos (como WordPress), aplicaciones empresariales y proyectos que requieren manejar datos de forma estructurada.
